# SuzumetryDash 
Basic telemetry for Assetto Corsa, Assetto Corsa Competizone, and Dirt Rally 2.0 _only tested on Assetto Corsa_
Stream to browser via local network and wifi, thus can display on a phone or normal browser

*if unable to connect to browser e.g no connection, make sure to open your ports as follows:*
| Port | Powershell |
| --- | --- |
| 8080 | netsh advfirewall firewall add rule name="Suzumetry" dir=in action=allow protocol=TCP localport=8080 |
